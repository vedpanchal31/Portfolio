## 💻 About This Portfolio Repository

This repository contains the source code for my personal developer portfolio, built with modern web technologies and clean architecture.

### Tech Stack
- **Framework:** React 19 + TypeScript (strict mode)
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React & custom SVGs

### Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vedpanchal31/ved-panchal-portfolio.git
   cd ved-panchal-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
